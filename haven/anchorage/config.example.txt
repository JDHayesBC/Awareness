#   - One "key = value" per line. Whitespace around "=" is trimmed.

#   - Blank lines are ignored. Key order is free.

#   relay    Haven relay base URL, NO trailing slash, NO inline comment
#   secret   from haven/data/anchorage-sl-secret.txt (shared by both entities)
#   primary  true on EXACTLY ONE prim (it voices the humans' lines); false elsewhere
